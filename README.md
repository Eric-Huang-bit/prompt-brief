# Prompt Brief：项目需求增强

版本：**1.0**。

第一版是可安装的 Codex Skill，面向**现有代码项目的功能开发需求**。通过当前代理读取相关代码、补齐关键决策，输出有依据的提示词和修改对照。默认停在预览；没有额外 API、账号或常驻服务。

## 使用

下载本仓库后，将 `skills/prompt-brief` 目录复制到 `~/.codex/skills/`（Windows 通常为 `%USERPROFILE%\.codex\skills\`），然后在目标代码项目的新会话中调用。

仓库保留可编辑源码。已有同名技能时先比较内容，不直接覆盖。

在能访问目标代码仓库的 Codex 会话中调用：

```text
用 $prompt-brief 优化这个需求：给商品列表增加搜索，保持现有样式。
```

也支持“只做最小修改，不读项目”或“不要提问，未确定的地方保留占位项”。只有用户明确要求优化后直接执行，且关键决策已解决，才继续实现。

预期结果是项目依据、可复制提示词、修改对照。它不在输入框中拦截文字，也不会添加一键增强按钮。没有项目上下文时会降级为明确标注局限的文本整理。

## 产品边界

- 第一版关注功能开发，不包含多平台 UI、快捷键、团队云端历史或自动优化循环。
- 不承诺提高完成率；效果由真实任务评测决定。
- 支持中文或用户使用的语言，不把中文输入自动翻译成英文。
- 技能使用已有代理的能力，不另发第三方优化请求；读取范围仍需控制在任务所需内容。

## 验证与后续

`eval/cases.jsonl` 提供 20 个合成行为评测用例，覆盖需求保真、项目证据、澄清与执行边界；`eval/regression-cases.jsonl` 提供 8 个针对性回归用例。执行方式见 [评测说明](eval/README.md)，实际结果和已知局限见 [验证记录](eval/validation-v2.md)。合成用例的结果不代表真实项目完成率。

最小示例见 [示例预览](examples/preview.md)。将技能放进真实项目后，先收集用户修改和拒绝增强结果的原因，再决定是否增加客户端界面。
